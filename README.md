# Dreams of a World

## Layout
- `index.html` is the homepage. Its article list is the `articles-data` block near the bottom of the file.
- Each article is one page named after it (`a-future-worth-building.html`) plus its cover image (`a-future-worth-building.jpg`).

## Adding an article
1. Upload the new article's `.html` page and `.jpg` cover (Add file → Upload files).
2. Replace `index.html` with the updated version that lists the new article.
3. Commit. The site updates within a minute or two.

# Dreams of a World

Essays by Symon Petlura, published with GitHub Pages.

## Layout
- `index.html` is the homepage. Its article list is the `articles-data` block near the bottom of the file.
- Each article has its own folder (`a-future-worth-building/`) with its `index.html` and `cover.jpg`.

## Adding an article
1. Upload the new article folder (Add file → Upload files, then drag the folder in).
2. Replace `index.html` with the updated version that lists the new article.
3. Commit. The site updates within a minute or two.
